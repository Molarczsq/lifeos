# 用户名注册流程更新

## 行为
用户名 + 密码 + 服务端图案验证码注册到数据库，成功后自动签发会话Cookie。登录只需用户名和密码。刷新页面通过Cookie恢复账户，再加载该账户的数据库记录；退出后私有缓存清空。未登录时不渲染导航和AI入口。

## 兼容旧数据库
启动时将 users.email 原地重命名为 username，不改变用户ID、密码哈希、会话或健康记录。旧账户继续用原完整邮箱登录。迁移可重复运行，SQLite迁移测试已通过；生产升级前保留数据库备份。不要执行 docker compose down -v。

## 验证记录
本地 TypeScript 类型检查通过。10项不依赖网络的测试通过：注册入库、哈希会话、验证码错误后不可重用、验证码绑定/过期、大小写重复用户名、数据库密码比对、Cookie轮换与注销、旧数据库迁移，以及原有营养/供应商校验。

已新增HTTP集成测试及2条移动端E2E：正常注册→记录→聊天→刷新→退出→重新登录恢复记录→另一账户隔离；错误验证码拒绝后刷新并重试。当前会话沙箱无法使用套接字，完整HTTP测试、Next生产构建及GitHub云端结果待运行环境恢复后验证，不计为通过。
