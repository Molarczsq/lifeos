# 产品使用指南

1. 注册或登录独立账户，了解并调整数据与隐私授权。
2. 在“饮食建档”中填写偏好，也可逐题跳过。未提供的信息不会被当成默认答案；刷新后可继续，完成后核对保存。
3. 用图片识餐或手动记录，确认食材与份量后保存。图片和营养信息为估计。
4. 输入预算、食材与本次要求，生成下一餐；确认前不会写入饮食历史。
5. 在“怎么做菜”自由添加食材、数量、厨具和排除项，生成步骤后可继续提出修改要求。
6. 在“问问智膳”查看推荐问题。点击才发送，通用问题明确标注；引用可追溯，历史会话按用户隔离。
7. 可以导出数据、删除记录或撤回授权。没有模型配置时仍可手动管理记录，但不会把模拟菜谱当成真实AI生成。

测试数据应使用独立账户与合成内容。真实视觉能力需要支持图片的供应商，文本模型成功不等于识图成功。产品不提供疾病诊断、治疗或药物处方。
